# Job Application Tracker — Take-Home #1 starter

This branch is **a scaffolded project — the data, the stylesheet and an entry point**.

Full instructions and the grading rubric: <https://go.prmf.org/355/takehomes/1>

## Run it

```bash
npm install
npm run dev
```

## What you are given

- `src/applications.js` — the applications, already written
- `src/statuses.js` — the status names, labels and a date formatter
- `src/index.css` — every class you need; you should not have to write CSS

## What you add

- Break the page into components, each in its own file
- Render the list with map() and stable keys
- Show a status badge, and hide fields that are empty
- Calculate the summary counts from the data

# Student Portion - Take Home Website Explained

## What it is
This app is a data parsing React project, taking applications from a compiled json list and putting it into an easily comprehendable format.
Components are utilized that seperately take data and display it in uniform fashion to the main page.

## How to run it
To run, simply use a git bash terminal after copying the project files and command lining into the head folder

```bash
npm i 
npm run dev
```

This will install the necessary dependencies for the project, then subsequently run it.
