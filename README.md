# Student Portion - Take Home Website Explained

## What it is
This app is a data parsing React project, taking applications from a compiled json list and putting it into an easily comprehendable format.
Components are utilized that seperately take data and display it in uniform fashion to the main page.

## How to run it
To run, simply use a git bash terminal after copying the project files and command lining into the head folder

```bash
npm i 
npm run dev
```

This will install the necessary dependencies for the project, then subsequently run it.
